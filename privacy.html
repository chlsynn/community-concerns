Privacy

Ipinapaliwanag ng pahinang ito kung anong impormasyon ang kinukuha ng website na ito at paano ito ginagamit.

Ang inilalagay mo

Kapag nagpadala ka ng report, sine-save ng site ang klase ng problema, ang lugar, ang paliwanag, ang petsa at oras ng report, at ang pangalan mo kung nilagay mo. Hindi kailangang ilagay ang pangalan. Kapag walang pangalan, ang makikita ay "Hindi nagpakilala".

Sino ang makakakita

Pampubliko ang mga report. Sinumang magbukas ng site na ito ay makakabasa ng lahat ng report, kasama ang lugar, paliwanag, at pangalan na nilagay mo. Huwag maglagay ng numero ng telepono, tirahan ng ibang tao, o iba pang pribadong detalye sa report.

Ano ang magagawa ng mga admin

Ang mga admin na naka-login ay puwedeng magpalit ng katayuan ng report, magdagdag o magbago ng mensahe para sa mga residente, at magbura ng report. Protektado ng email at password ang mga admin account.

Saan naka-save ang data

Ang mga report at admin account ay naka-save sa database ng Supabase. Ang website ay naka-host sa Vercel. Maaaring magtago ang dalawang serbisyong ito ng technical logs tulad ng IP address bilang bahagi ng normal nilang operasyon, ayon sa sarili nilang patakaran.

Cookies at tracking

Walang ads, analytics, o tracking script ang site na ito. Kapag nag-login ang admin, nagtatabi ang browser ng login session para hindi na kailangang mag-login ulit. Ang mga bisitang hindi nag-login ay walang itinatabi ang site na ito sa kanilang browser, maliban sa napili nilang wika.

Pagtanggal ng report

Kung may personal na impormasyon mo sa isang report at gusto mo itong tanggalin, makipag-ugnayan sa admin ng site at sabihin kung aling report ito. Puwede itong burahin ng admin.

Tungkol sa proyektong ito

Ginawa ang site na ito bilang proyekto sa klase. Hindi ito opisyal na sistema ng gobyerno.

Privacy

This page explains what this website collects and how it is used.

What you submit

When you submit a report, the site stores the category, the location, the description, the date and time of the report, and your name if you choose to enter one. The name is optional. Leaving it blank shows the report as Anonymous.

Who can see it

Reports are public. Anyone who opens this site can read every report, including the location, description and name you entered. Do not include phone numbers, home addresses of private individuals, or other personal details in a report.

What administrators can do

Signed-in administrators can change a report's status, add or edit a note for residents, and delete reports. Administrator accounts are protected by an email and password.

Where the data is stored

Reports and administrator accounts are stored in a database hosted by Supabase. The website is hosted by Vercel. Both services may keep technical logs such as IP addresses as part of normal operation, under their own policies.

Cookies and tracking

This site has no advertising, no analytics and no tracking scripts. When an administrator logs in, the browser stores a login session so the administrator stays signed in. Visitors who do not log in have nothing stored by this site, except the language they chose.

Removing a report

If a report contains your personal information and you want it removed, contact the site administrator and describe the report. Administrators can delete it.

About this project

This site was built as a class project. It is not an official government system.
